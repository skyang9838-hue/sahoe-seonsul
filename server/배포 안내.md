# 서버 배포 안내 (선생님이 할 일)

게임과 교사 화면은 GitHub Pages에 올라가고, **답안 저장과 채점 기록만** 선생님 구글 계정의 구글 시트 + Apps Script가 맡습니다.
아래를 한 번만 하면 됩니다. 20분쯤 걸립니다.

> 배포하기 전에는 `game/src/config.js`의 `API_URL`이 비어 있어서, 게임·교사 화면이 **그 컴퓨터 브라우저 안에서만** 저장되는 시험 모드로 돕니다(교사 화면 시험 비밀번호 `teacher`). 실제 수업 전에 꼭 아래를 끝내 주세요.

## 1. 구글 시트 만들기
1. 구글 드라이브 → 새로 만들기 → Google 스프레드시트.
2. 이름은 알아보기 쉽게, 예: `꼬꼬의 첫 출근 답안 (6학년)`.
3. 탭은 만들지 않아도 됩니다. 처음 접속이 들어올 때 `답안`·`채점`·`설정` 탭이 저절로 생깁니다.
   - 미리 만들고 싶으면 3단계 뒤에 편집기에서 `setup` 함수를 한 번 실행하세요. `답안`·`채점`·`설정`·`명단`·`인정단어`(숨김) 다섯 탭이 생깁니다.
4. 이 시트는 **선생님만** 편집할 수 있게 둡니다(공유하지 않기). 학생은 시트를 보지 않고 웹앱으로만 저장합니다.

## 2. Apps Script에 코드 붙여 넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, 저장소의 `server/Code.gs` 내용을 통째로 붙여 넣습니다.
3. 위쪽 디스크 모양(저장)을 누릅니다.

## 3. 교사 비밀번호 넣기 (TEACHER_PW)
1. Apps Script 왼쪽 톱니바퀴 **프로젝트 설정**.
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**.
3. 속성 `TEACHER_PW`, 값 = 교사 화면에서 쓸 비밀번호(학생이 짐작하기 어려운 것). **저장**.
   - 비밀번호는 코드나 저장소에 넣지 않습니다. 바꾸고 싶으면 이 값만 고치면 됩니다.
   - 10번 연속 틀리면 10분 동안 로그인을 막습니다. 로그인하면 6시간 동안 다시 묻지 않습니다.

## 4. 인정 단어 넣기 (한 번만)
인정 단어 목록은 학생이 보면 답이 새므로 저장소(공개)에 없습니다. 이 컴퓨터의 `server/private/keywords.json`에만 있습니다.
1. Apps Script 왼쪽 **파일 옆 +** → **스크립트** → 이름 `붙여넣기`.
2. 그 파일 내용을 지우고 아래처럼 한 줄을 씁니다. `{ … }` 자리에 `server/private/keywords.json` 내용을 **통째로** 붙여 넣습니다.
   ```
   var KEYWORDS_PASTE = { … };
   ```
3. 저장 → 위쪽 함수 고르기에서 **`setupKeywords`** → **실행**.
   - 처음 실행하면 권한 승인 창이 뜹니다: 계정 고르기 → "고급" → "(안전하지 않음)으로 이동" → 허용. 선생님 시트에만 쓰는 권한입니다.
4. 아래 **실행 로그**에 `인정 단어를 넣었어요 (… a0:기호 a1:기호 a2:… )`가 보이면 성공입니다. 시트에 숨김 탭 `인정단어`가 생깁니다.
5. **`붙여넣기` 파일은 지웁니다**(파일 옆 ⋮ → 삭제). 단어는 숨김 탭에 남아 있습니다.
   - 인정 단어를 고치면 `keywords.json`을 고친 뒤 1~5를 다시 하면 됩니다(숨김 탭을 통째로 바꿉니다).
   - 숨김 탭 `인정단어`는 지우거나 고치지 마세요.

## 5. 웹앱으로 배포
1. Apps Script 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설명: `꼬꼬 서버 1`(아무거나).
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** (학생은 구글 로그인 없이 저장해야 하므로)
4. **배포** → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 확인: 그 주소를 브라우저에 붙여 넣으면 `{"ok":true,"msg":"꼬꼬의 첫 출근 서버가 켜져 있어요. …"}`가 보여야 합니다.

## 6. 게임에 주소 넣기
1. 저장소 `game/src/config.js`의 `API_URL = ''` 따옴표 안에 5단계 주소를 넣습니다.
   ```js
   export const API_URL = 'https://script.google.com/macros/s/…/exec';
   ```
2. 커밋·push → GitHub Pages가 다시 올라가면 끝. (클로드에게 "API 주소 넣어 줘"라고 해도 됩니다.)

## 수업 전 점검 (5분)
1. 게임 주소에서 **반 9 · 번호 99** 같은 시험 번호로 들어가 몇 글자 쓰고 제출 → 시트 `답안` 탭에 그 줄이 생기는지.
2. 교사 화면(`게임 주소/teacher.html`)에서 비밀번호로 로그인 → 9반이 보이는지 → 판정 하나 눌러 `채점` 탭에 들어가는지.
3. 9반 **마감** → 게임에서 그 번호로 다시 들어가면 "선생님이 마감했어요"·읽기 전용인지 → 마감 풀기.
4. 시험 줄은 `답안`·`채점`·`설정` 탭에서 행을 지우면 됩니다.

## 쓰면서 알아 둘 것
- **명단(선택)**: 이름을 보고 싶으면 `명단` 탭에 `반 | 번호 | 이름`을 직접 붙여 넣습니다(1행 머리줄은 그대로). 앱은 학생 명단 파일을 읽지 않습니다.
- **마감**: 교사 화면의 [반 마감]을 누르면 그 반 학생은 더 고칠 수 없습니다(제출 표시는 남음). 다시 누르면 풀립니다. `설정` 탭에서 그 반 `마감` 칸을 지워도 풀립니다.
- **탭의 열을 끼우거나 지우지 마세요.** 머리줄이 달라지면 서버가 그 탭에 쓰지 않고 오류를 냅니다(엉뚱한 칸에 쓰지 않게). 채점 메모는 `답안`·`채점` 탭의 **오른쪽 빈 열(Q열·N열부터)**에 적으면 안전합니다.
- **코드를 고친 뒤**에는 배포 → **배포 관리** → 연필 → 버전 "새 버전" → 배포. (새 배포를 만들면 주소가 바뀌니 기존 배포를 고칩니다.)
- 학생은 반·번호만으로 들어가므로, 다른 학생 번호로 들어가면 그 답이 보입니다. 수업 중 자기 번호로만 들어가도록 안내해 주세요.
